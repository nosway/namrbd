# NAMRBD Licensing Policy

Unless a file or directory contains a different license notice, NAMRBD source
code and documentation are licensed under the Apache License, Version 2.0. The
complete default license text is in [`LICENSE`](LICENSE).

The Linux kernel module sources under `kernel/module/` are licensed under
GPL-2.0-only. Those files carry SPDX license identifiers and must remain
compatible with the Linux kernel module licensing boundary.

Vendored or forked third-party source retains its upstream license. The
NAMRBD-managed gotgt fork under `third_party/gotgt/` preserves its upstream
Apache-2.0 license and records project patches in
`third_party/gotgt/NAMRBD_PATCHES.md`.

Additional license texts are provided under `LICENSES/`, and included
third-party notices are summarized in `THIRD_PARTY_NOTICES.md`.
